# StayOps — Hospitality & Property Management System

StayOps is a modern Property Management System (PMS) designed for homestays, resorts, boutique hotels, and villas.

## Features
- **Frontdesk & Reservations**: Real-time room inventory, visual calendar, check-in/out workflows.
- **Petty Cash Ledger**: Real-time float management, caretaker expense logging with receipt photo verification, and multilingual localization (English, Hindi, Tamil, Kannada).
- **Storefront & Theme Engine**: Highly customizable guest booking storefronts with instant live preview.
- **Housekeeping & Staff Portal**: Instant room cleaning status updates and photo evidence submission.
- **PWA Ready**: Progressive Web App with offline caching and native mobile app feel.

## Tech Stack
- **Frontend**: React 19, Vite, TailwindCSS, React Icons
- **Backend**: Spring Boot, Spring Security (JWT), WebSocket, MySQL / JPA
